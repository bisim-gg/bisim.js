# معرفی

bisim.js کتاب‌خانهٔ رسمی Node.js برای ساخت ربات روی [بی‌سیم](https://bisim.gg) است. ظاهر عمومی آن از
discord.js نسخهٔ ۱۴ پیروی می‌کند: همان کلاس‌ها، متدها، رویدادها، شیءهای تنظیمات و سازنده‌ها. اگر پیش‌تر ربات
discord.js نوشته‌اید، نوشتن ربات بی‌سیم را هم بلدید.

```js
const { Client, Events, GatewayIntentBits } = require('bisim.js');

const client = new Client({ intents: [GatewayIntentBits.Guilds] });

client.once(Events.ClientReady, (readyClient) => {
  console.log(`${readyClient.user.tag} is online.`);
});

client.login(process.env.BISIM_TOKEN);
```

## bisim.js چطور کار می‌کند

bisim.js در پشت صحنه با API و گیت‌وی خود بی‌سیم حرف می‌زند. بی‌سیم ساختار JSON خودش را دارد (نام‌گذاری
camelCase و شناسه‌ها به‌صورت رشته)، اما برای نوع‌ها، پرچم‌ها و بیت‌های دسترسی همان عددهای دیسکورد را به کار
می‌برد. به همین دلیل bisim.js می‌تواند هر شیء بی‌سیم را به همان شیئی تبدیل کند که از discord.js انتظار دارید:
یک `Message`، یک `GuildMember` یا یک `ChatInputCommandInteraction`.

بعضی امکانات در دیسکورد هست و در بی‌سیم نیست؛ مثل رشته‌ها (threads)، کانال‌های استیج و اتصال صوتی برای
ربات‌ها. bisim.js هیچ‌کدام را بی‌صدا نادیده نمی‌گیرد: فراخوانی آن‌ها یک `BisimjsError` می‌دهد که می‌گوید این
امکان در بی‌سیم پشتیبانی نمی‌شود. فهرست کامل در صفحهٔ [آمدن از discord.js](./moving-from-discord-js.md) آمده است.

## ساختار این راهنما

- **شروع کار**: نصب Node.js و bisim.js، ساخت برنامه در بی‌سیم و اجرای نخستین ربات.
- **دستورهای اسلش**: ساخت، ثبت و پاسخ دادن به دستورها، همراه با گزینه‌ها، تکمیل خودکار، دسترسی‌ها و نام‌های
  فارسی و انگلیسی.
- **تعامل‌ها**: دستورهای منوی راست‌کلیک، دکمه‌ها، منوهای انتخاب، فرم‌ها و دریافت تعامل‌ها از راه HTTP.
- **موضوع‌ها**: رویدادها، امبدها، پیام‌ها، اعضا و نقش‌ها، جمع‌کننده‌ها و شیوهٔ کار گیت‌وی در بی‌سیم.

همهٔ نمونه‌کدها جاوااسکریپت ساده (CommonJS) هستند. bisim.js تایپ‌های خودش را همراه دارد، پس همین کدها در
TypeScript هم کار می‌کنند و به جای `require` می‌توانید از `import` استفاده کنید.

## پیش از شروع

این‌ها را لازم دارید:

- [Node.js](https://nodejs.org) نسخهٔ ۱۸ یا جدیدتر.
- یک حساب بی‌سیم و سروری که بتوانید ربات را به آن اضافه کنید (دسترسی مدیریت سرور در آن لازم است).
- کمی جاوااسکریپت: تابع، شیء، `async` و `await`.

وقتی آماده بودید، به صفحهٔ [نصب](./installing.md) بروید.
